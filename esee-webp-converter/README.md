# Esee Automatic WebP

افزونهٔ مستقل وردپرس برای تبدیل خودکار تصاویر جدید به WebP با کیفیت پیش‌فرض ۸۸.

## امکانات

- تبدیل خودکار JPEG، PNG، BMP، AVIF و در صورت پشتیبانی سرور HEIC/HEIF
- اجرا در مسیر استاندارد آپلود وردپرس و سازگار با گوتنبرگ، ویرایشگر کلاسیک، ووکامرس و صفحه‌سازها
- حفظ GIF برای جلوگیری از حذف انیمیشن
- حفظ جهت صحیح عکس بر اساس EXIF قبل از تبدیل
- تنظیم کیفیت بین ۸۰ تا ۱۰۰ از مسیر «تنظیمات ← رسانه»
- امکان نگه‌داشتن فایل اصلی
- ادامهٔ امن آپلود با فایل اصلی در صورت پشتیبانی‌نشدن قالب یا خطای تبدیل
- بدون نیاز به Ghostscript

## نصب

1. فایل ZIP افزونه را از مسیر «افزونه‌ها ← افزودن افزونه تازه ← بارگذاری افزونه» نصب کنید.
2. افزونهٔ **Esee Automatic WebP** را فعال کنید.
3. در صورت نیاز، کیفیت را از «تنظیمات ← رسانه» تغییر دهید.
4. یک عکس جدید در کتابخانهٔ رسانه بارگذاری کنید.

## نکتهٔ HEIC/HEIF

نگاشت‌های زیر به وردپرس اضافه می‌شوند:

- `image/heic` → `image/jpeg`
- `image/heif` → `image/jpeg`
- `image/heic-sequence` → `image/jpeg`
- `image/heif-sequence` → `image/jpeg`

این نگاشت به معنی توانایی خواندن HEIC در همهٔ سرورها نیست. GD معمولاً HEIC/HEIF را باز نمی‌کند؛ برای ورودی‌های HEIC/HEIF باید Imagick/ImageMagick یا یک ویرایشگر تصویر وردپرس با پشتیبانی HEIC روی سرور فعال باشد. اگر این قابلیت وجود نداشته باشد، افزونه فایل آپلودشده را خراب یا حذف نمی‌کند.

Ghostscript برای ساخت پیش‌نمایش PDF استفاده می‌شود و در تبدیل عکس‌های این افزونه نقشی ندارد.
