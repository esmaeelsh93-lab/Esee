WooCommerce order notices via official WhatsApp, Bale, and Rubika HTTP APIs. No VPS. No unofficial number scanning.

== Description ==

Customers opt in at checkout. Messages are queued with Action Scheduler / WP-Cron and sent with a single short HTTP request to the official APIs.
