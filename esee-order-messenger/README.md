# پیام‌رسان سفارش Esee

افزونه ووکامرس برای اطلاع‌رسانی سفارش از **واتساپ، روبیکا و بله** بدون VPS و بدون فشار روی هاست.

## چیزی که این افزونه انجام نمی‌دهد

اسکن پنهان شماره برای فهمیدن اینکه «این خط واتساپ / روبیکا / بله دارد یا نه» با API رسمی ممکن نیست:

- واتساپ Cloud API متد جداگانه برای چک حساب ندارد.
- روبیکا فقط با `chat_id` بعد از استارت بات پیام می‌فرستد.
- بازوی بله هم معمولاً `chat_id` می‌خواهد (مگر حساب سازمانی سفیر).

روش‌های «چک وجود حساب» غیررسمی به نشست واتساپ وب و سرور همیشه روشن نیاز دارند؛ همان VPS و باری که نمی‌خواهید.

## کاری که انجام می‌شود

1. مشتری هنگام تسویه‌حساب تیک می‌زند: واتساپ / روبیکا / بله.
2. بعد از ثبت سفارش، یک جاب کوتاه در Action Scheduler (یا WP-Cron) صف می‌شود.
3. هاست فقط **یک درخواست HTTP هشت‌ثانیه‌ای** به سرور متا / بله / روبیکا می‌زند.
4. وقتی سفارش **تکمیل** شود، متن شخصی‌سازی‌شده جداگانه ارسال می‌شود.

اگر واتساپ خطایی مثل «قابل تحویل نیست» (کد 131026) برگرداند، تیک واتساپ همان سفارش برداشته می‌شود؛ این نزدیک‌ترین تشخیص رسمی است، نه اسکن قبل از ارسال.

برای روبیکا و بازوی بله، در صفحه تشکر لینک استارت بات نشان داده می‌شود تا `chat_id` با وب‌هوک ذخیره شود.

## نصب

پوشه `esee-order-messenger` را در `wp-content/plugins` بگذارید و افزونه را فعال کنید. مسیر تنظیمات: ووکامرس → پیام‌رسان سفارش.

## متغیرهای متن

`{order_id}` `{first_name}` `{last_name}` `{phone}` `{total}` `{status}` `{items}` `{custom_note}`
