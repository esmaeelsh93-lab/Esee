# نصب قالب Bahar Shop

1. فایل ZIP را باز کنید؛ داخل آن باید پوشهٔ `bahar-shop` باشد.
2. کل پوشهٔ `bahar-shop` را در مسیر زیر کپی کنید:
   `wp-content/themes/bahar-shop`
3. داخل پوشه باید این فایل‌ها دیده شوند:
   - `style.css`
   - `functions.php`
   - `index.php`
4. از پیشخوان وردپرس → نمایش → پوسته‌ها قالب را فعال کنید.
5. کش LiteSpeed را پاک کنید.

اگر خطای «قالب پیدا نشد / index.php» دیدید، یعنی محتویات ZIP را مستقیم در themes ریخته‌اید یا پوشه تو در تو شده. فقط یک لایه: `themes/bahar-shop/index.php`.
