# بهار شاپ — خلاصه پروژه و تغییرات (Bahar Shop Theme)

> این فایل خلاصه‌ی کارها و نکات مهم پروژه است تا بعداً به مشکل نخوریم.
> آخرین نسخه تم: **1.17.0**

---

## نسخه ۱.۱۷.۰ — پولیش UI + پایداری تنظیمات + اسلایدر سبلان
- **حذف حالت شب/روز:** دکمه تم و اسکریپت‌های dark mode از فرانت حذف شد.
- **پایداری تنظیمات:** sanitize روی مقدار ذخیره‌شده فعلی؛ هر تب فقط option خودش را ذخیره می‌کند؛ URL هاردکد هیرو از defaults حذف شد.
- **هیرو بک‌اند:** آپلود جداگانه دسکتاپ/موبایل از Media Library + پیش‌نمایش + ذخیره Attachment ID + alt + ابعاد پیشنهادی؛ fallback گرادیان نرم اگر عکسی نباشد.
- **اسلایدر تخفیف:** تشخیص محصولات on-sale ووکامرس شامل محصولات متغیر و تخفیف‌های افزونه سبلان (دیگر فقط `_sale_price` والد نیست).
- **UI:** پالت صورتی/بنفش ملایم، جداکننده هاله‌ای بین سکشن‌ها، کارت محصول و دسته تمیزتر، هیرو جذاب‌تر.

## نسخه ۱.۱۶.۰ — تنظیمات حرفه‌ای + هدر موبایل + بارگذاری بیشتر
- **نام‌گذاری:** حذف اشاره به «پریسا» از تنظیمات؛ برچسب خنثی «حالت امن».
- **هیرو (بک‌اند):** متن برند/شعار/دکمه، رنگ‌ها، جای‌گذاری دسکتاپ/موبایل، متن و دکمه اضافه، CSS اختصاصی.
- **هدر موبایل:** همبرگر + سوشیال لبه‌ی راست تصویر؛ سبد/حساب/تم لبه‌ی چپ؛ رنگ هدر، سوشیال، نمایش/مخفی المان‌ها + CSS.
- **عکس کارت:** عرض و ارتفاع دسکتاپ/موبایل در تنظیمات.
- **نوار پایین:** CSS اختصاصی.
- **فوتر:** توضیح قابل ویرایش + بلوک اضافه (عنوان/متن/دکمه/لینک) + CSS.
- **دکمه‌ها:** رنگ «دیدن محصول»، انتخاب گزینه‌ها، افزودن به سبد، گردی گوشه + CSS.
- **فروشگاه/دسته:** «بارگذاری بیشتر» به‌جای صفحه‌بندی کلاسیک.

## نسخه ۱.۱۵.۰ — هیرو موبایل تمام‌عرض + ناوبری + عکس‌ها
- **هیرو موبایل:** بدون قاب، تمام‌عرض، حدود نصف صفحه؛ «بهار شاپ» بالا، «انتخاب دخترای تاپ» زیرش، «دیدن جدیدترین‌ها» گوشه پایین چپ.
- **هدر موبایل:** لوگو سبز حذف؛ همبرگر + اینستا + واتساپ + تماس (فقط آیکون) سمت راست.
- **سبد:** بج تعداد روی هدر و نوار پایین (با fragment زنده).
- **فوتر:** حذف آدرس از لندینگ؛ حذف دو نقطه از خط طراح؛ آیکون‌های اینستا/واتساپ/تماس.
- **کارت محصول:** بج‌های تخفیف/جدید افقی؛ قلب کنار «دیدن محصول».
- **بک‌اند:** تنظیم ابعاد/پر کردن قاب عکس + «حالت امن» برای برگشت به contain.
- **نوار پایین:** رنگ هم‌خوان با برند (صورتی/اورکید) + آیکون بزرگ‌تر.

## نسخه ۱.۱۴.۰ — هدر فشرده + دسته‌ها + اسلایدر تخفیف + فیکس سبد موبایل
- **هدر دسکتاپ:** نوار بالایی (اینستا/تلفن/شعار) داخل هدر ادغام شد؛ منو در همان خط لوگو (جمع‌وجورتر).
- **هیرو:** عکس با `object-fit: contain` کامل نمایش داده می‌شود (بدون برش).
- **جستجو:** انیمیشن رد شدن نور روی نوار جستجو (موبایل + دسکتاپ).
- **دسته‌بندی‌ها:** بدون تکرار (حذف لوپ GSAP + dedupe در PHP)؛ دسکتاپ: گرید ۴ ستونه قاب‌دار زیر سرچ؛ موبایل: انیمیشن راهنمای اسکرول.
- **اسلایدر تخفیف:** بخش جدید صفحه اصلی + تنظیمات پیشخوان (روشن/خاموش + سرعت).
- **موبایل محصول:** نوار افزودن به سبد بالای نوار ناوبری پایین (دیگر گم نمی‌شود).
- **فوتر:** «طراح سایت :| اسماعیل شجاعی | 09036994450».

- جمله‌های راهنمای انتخاب متغیر (مثل «طرح مورد نظرت رو انتخاب کن:)») از توضیح کوتاه جدا می‌شوند و در باکس صورتی **دقیقاً بالای دکمه‌های متغیر** نمایش داده می‌شوند (`inc/variations-ui.php`).
- نوار چسبان پایین صفحه در موبایل (`≤768px`): قیمت + دکمه افزودن به سبد (`inc/sticky-cart.php` + `assets/js/sticky-cart.js`).
- دکمه ضربدر «پاک کردن انتخاب» وقتی متغیری انتخاب شده باشد نمایش داده می‌شود.
- استایل‌ها در `assets/css/woocommerce.css`.
- فایل‌های آپلود: `functions.php`، `style.css`، `inc/variations-ui.php`، `inc/sticky-cart.php`، `inc/setup.php`، `assets/js/sticky-cart.js`، `assets/js/variations.js`، `assets/css/woocommerce.css`.

## نسخه ۱.۷.۰ — مگامنوی پویا و شیشه‌ای فروشگاه
- افزودن کلاس `SHJ_Dynamic_Mega_Menu` در فایل جدید `inc/mega-menu.php` (لود از `functions.php`).
  - دسته‌های محصول را به‌صورت پویا با عکس، تعداد محصول و زیر‌دسته‌ها نمایش می‌دهد.
  - خروجی با `transient` به‌مدت ۱۲ ساعت کش می‌شود؛ با افزودن/ویرایش/حذف دسته یا ذخیره‌ی محصول، کش خودکار پاک می‌شود.
  - ستون‌ها از زیرمجموعه‌های دسته‌ی پایه («پوشاک دخترانه»/`all`) ساخته می‌شوند تا با ساختار واقعی سایت بخورد (در نبود آن، fallback به دسته‌های سطح‌اول).
- بازنویسی ناوبری در `header.php` با ساختار جدید `shj-main-navigation` (خانه / فروشگاه + مگامنو / بلاگ / پنل کاربری). شناسه‌ی `primary-nav` حفظ شد تا دکمه‌ی همبرگری موبایل کار کند.
- افزودن استایل گلاسمورفیک مگامنو به انتهای `assets/css/main.css` (هماهنگ با پالت صورتی تم و واکنش‌گرا در `≤900px`).
- **توجه:** CSS در `assets/css/main.css` اضافه شد، نه `style.css`، چون در این تم فقط `main.css` بارگذاری می‌شود.
- فایل‌هایی که باید روی هاست آپلود شوند: `functions.php`، `style.css`، `header.php`، `inc/mega-menu.php`، `assets/css/main.css`.

## ۳) خلاصه‌ی تغییرات اخیر

### بنر هیرو (صفحه اصلی)
- بنر اختصاصی موبایل و دسکتاپ با `<picture>` (هرکدام فقط عکس خودش لود می‌شود).
- نوشته‌ی روی بنر («با من اینجا استایلت رو بساز») حذف شد.
- دکمه‌های بالای بنر (فروشگاه + اینستا) حذف شدند.
- خودِ عکس بنر لینک فروشگاه است (کلیک روی عکس → فروشگاه).
- پدینگ قاب کم شد تا عکس بزرگ‌تر و تقریباً تمام‌قاب شود.

### هدر
- دکمه اینستاگرام (صورتی شیشه‌ای) کنار آیکون منو (همبرگری) اضافه شد — فقط موبایل.
- روی دسکتاپ، اینستا در نوار بالایی (top-bar) است (تکراری نشود).
- لوگوی موبایل/دسکتاپ جدا (`site-logo--mobile` / `site-logo--desktop`).

### منو
- ایموجی‌های دستیِ آیتم‌های منو **خودکار حذف** می‌شوند.
- برای هر دسته بر اساس نامش یک ایموجی مناسب گذاشته می‌شود، داخل حلقه‌ی شیشه‌ای نئونی.
- نقشه‌ی دسته→ایموجی در `inc/setup.php` تابع `bahar_shop_menu_icon_for()` است (پیش‌فرض 🌸).

### بخش‌های دیگر (قبل‌تر انجام شده)
- جستجوی هوشمند صفحه اصلی (`inc/search.php` + `assets/js/search.js` + `template-parts/home-search.php`).
- متغیرهای محصول به‌صورت دکمه‌ای کنار هم + ضربدر روی ناموجودها (`inc/variations-ui.php` + `assets/js/variations.js`).
- صفحات سیاست/ارسال/مرجوعی به‌صورت خودکار ساخته می‌شوند (`inc/pages-content.php`).
- بهینه‌سازی موبایل سبد خرید و تسویه‌حساب.
- گالری محصول با `object-fit: contain` (عکس‌ها کامل دیده می‌شوند).

## ۵.۱) افزونه‌ی واحد: مدیریت محصولات ناموجود و لینک‌ساز داخلی بهار
مسیر: `wp-content/plugins/bahar-oos-manager/`  — نسخه ۱.۰.۰

این افزونه **جایگزینِ** «بهار اسمارت سوئیت» است و هر سه قابلیت را در یک افزونه و با **یک صفحه‌ی تنظیمات واحد** دارد:

- **مدیریت هوشمند محصولات ناموجود**: امتیازدهی بر اساس بازدید داخلی + فروش قبلی + مدت ناموجودی + کلیک/نمایش CSV سرچ کنسول + تصمیم دستی؛ سپس رفتار سئو (۳۰۲/۳۰۷/۳۰۱/۴۱۰)، مخفی‌سازی از آرشیو، پیام «ناموجود + مشابه‌ها» و اصلاح Schema به `OutOfStock`.
- **لینک‌دهی داخلی خودکار** (همان قابلیت قبلی، ادغام‌شده).
- **پیشنهاد هوشمند محصول** (همان قابلیت قبلی، ادغام‌شده). شورت‌کد: `[bahar_smart_products limit="4"]`.
- پنل: پیشخوان → **بهار OOS** (داشبورد، محصولات ناموجود، ایمپورت CSV، تنظیمات، گزارش ریدایرکت‌ها، ابزارها).
- جدول‌ها: `wp_bahar_oos_views`, `wp_bahar_oos_redirect_logs`. کران روزانه: `bahar_oos_daily_event`.
- وضعیت: ساخته شد ولی **هنوز فعال/تست نشده** (PHP محلی در دسترس نبود). قدم بعدی: غیرفعال/حذفِ «بهار اسمارت سوئیت» روی هاست، سپس فعال‌سازی این افزونه و زدن «اجرای بررسی حالا».

> افزونه‌ی قدیمی `bahar-smart-suite` از مخزن محلی حذف شد (نسخه‌اش در بکاپ ZIP موجود است). روی هاست هم باید غیرفعال/حذف شود تا قابلیت‌ها دوبار اجرا نشوند.
