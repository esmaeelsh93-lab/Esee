# قوانین فینگلیش‌سازی نامک (Damavand)

مرجع تصمیم‌گیری برای دیکشنری داخلی `includes/data/finglish-builtin-words.php`
و دیکشنری سفارشی فروشگاه در تنظیمات → نامک.

هدف: نامک لاتین خوانا برای گوگل و کاربر ایرانی، بدون ترجمه‌ی گمراه‌کننده.

## قاعدهٔ اصلی

| وضعیت واژه | انتخاب | مثال |
|---|---|---|
| معادل انگلیسی در بازار ایران رایج و قابل‌فهم است (جست‌وجوی فارسی/فروشگاهی همان را می‌نویسند) | **انگلیسی رایج** | هودی → `hoodie`، کراپ‌تاپ → `crop-top`، سویشرت → `sweatshirt`، دامن → `skirt` |
| واژه پوشاک/بومی است و معادل انگلیسی یا ناآشناست یا معنی را عوض می‌کند | **فینگلیش خام (آوانویسی)** | شلوار → `shalvar`، پیراهن → `pirahan`، مانتو → `manteau`، کلاه → `kolah`، چادر → `chador` |
| برند یا وام‌واژهٔ جاافتاده | همان لاتین رایج برند/کالا | جین → `jean`، دنیم → `denim`، پولو → `polo` |

### تست سریع قبل از افزودن کلید جدید

1. اگر مشتری ایرانی در سرچ/اینستاگرام همان واژهٔ انگلیسی را برای این کالا می‌زند → انگلیسی.
2. اگر انگلیسی باعث اشتباه شود (مثلاً `pants` برای شلوار پارچه‌ای ایرانی، یا `dress` برای پیراهن مردانه) → فینگلیش.
3. چند املای فارسی یک مفهوم (`تیشرت` / `تی‌شرت` / `تی شرت`) باید به **یک** اسلاگ برسند.
4. کلیدهای کوتاه خطرناک‌اند: فقط وقتی امن است اضافه کنید که تطبیق کل‌توکن باشد (موتور فعلی توکن‌محور است).

## ترتیب اعمال در موتور

1. دیکشنری سفارشی فروشگاه (Settings) — اولویت بالاتر روی همان کلید
2. دیکشنری داخلی این فایل PHP
3. نگاشت حرف‌به‌حرف (`char_map`) برای باقی‌مانده
4. حذف ایست‌واژه‌های نامک (`از`، `با`، `در`، `برای`، …)
5. یکتاسازی اسلاگ در صورت تکراری بودن

## نمونه‌های عمدی دوگانه در map فعلی

**انگلیسی رایج:** `hoodie`, `crop-top`, `tshirt`, `sweatshirt`, `blouse`, `coat`, `jacket`, `skirt`, `jumpsuit`, `polo`, `denim`, `cotton`, `leather`, …

**فینگلیش/آوانویسی:** `shalvar`, `shalvark`, `pirahan`, `manteau`, `palto`, `lebas`, `kolah`, `chador`, `maghnaeh`, `aba`, `kafsh`, `nakhi`, …

## چه چیزی را عوض نکنید

- اسلاگ یا ریدایرکت محصولات منتشرشده را با «بهبود دیکشنری» به‌صورت خودکار بازنویسی نکنید.
- فقط کلیدهای جدید/اصلاح دیکشنری برای پیشنهادهای بعدی و محصولات جدید.
