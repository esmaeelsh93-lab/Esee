چاپ گروهی و هوشمند سفارش‌های ووکامرس با HPOS، اندازه‌های کاغذ و ابعاد سفارشی.

== Description ==

افزونه «پرینت هوشمند شجاعی» امکان چاپ گروهی سفارش‌های ووکامرس را از پیشخوان فراهم می‌کند.

* تب جداگانه عملیات چاپ و تنظیمات
* هر سفارش در یک برگه جدا
* نمایش توضیحات مشتری روی فاکتور
* برچسب «نحوه ارسال»
* اندازه‌های A4 / A5 / A6 / Letter و ابعاد سفارشی (سانتی‌متر)
* بهینه‌سازی چاپ سیاه‌وسفید
* علامت چاپ‌شده برای سفارش‌هایی که قبلاً پرینت گرفته‌اند
* آپلود تصویر سربرگ از کتابخانه رسانه
* سازگار با HPOS و ذخیره‌سازی کلاسیک سفارش

== Installation ==

1. فایل ZIP را از افزونه‌ها → افزودن → بارگذاری افزونه نصب کنید.
2. افزونه را فعال کنید (ووکامرس باید فعال باشد).
3. از منوی ووکامرس → پرینت هوشمند شجاعی استفاده کنید.

== Frequently Asked Questions ==

= آیا سفارش‌ها را تغییر می‌دهد؟ =
خیر. فقط سفارش‌ها را می‌خواند، تنظیمات خودش را ذخیره می‌کند و سند چاپ می‌سازد.

= اندازه کاغذ سفارشی چگونه کار می‌کند؟ =
نوع کاغذ را روی «ابعاد سفارشی» بگذارید و عرض/طول را به سانتی‌متر وارد کنید (۵ تا ۱۰۰).
