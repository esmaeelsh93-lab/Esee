# Changelog

## 1.3.0

- جداسازی کامل تب‌های «عملیات چاپ» و «تنظیمات»
- چاپ هر سفارش در یک برگه فیزیکی جدا (`page-break-after` بدون صفحه خالی آخر)
- نمایش «توضیحات مشتری» روی فاکتور در صورت وجود
- تغییر برچسب به «نحوه ارسال»
- تنظیم نوع کاغذ: A4، A5، A6، Letter و ابعاد سفارشی (سانتی‌متر)
- اعتبارسنجی سروری ابعاد و حاشیه چاپ
- بهینه‌سازی ظاهر برای چاپگر سیاه‌وسفید
- علامت ✓ «چاپ‌شده» کنار سفارش‌هایی که قبلاً پرینت گرفته شده‌اند
- رفع آپلود تصویر سربرگ با WordPress Media Library (`wp.media`)
- سازگاری HPOS با `FeaturesUtil::declare_compatibility`
- بدون وابستگی Composer/Node در production
