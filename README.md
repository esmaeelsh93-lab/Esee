# Reza Jordaan

پوسته اختصاصی و راست‌چین فروشگاه اینترنتی [rezajordaan.ir](https://rezajordaan.ir) برای وردپرس و ووکامرس.

این پوسته یک پروژه مستقل با پوشه، شناسه تنظیمات، توابع، کلاس‌های نمایشی و دامنه ترجمه اختصاصی `rezajordaan` است.

## امکانات

- هدر واکنش‌گرا با منوی همبرگری، دسته‌بندی‌های پویا و لینک مستقیم اینستاگرام/واتساپ
- هیروی واکنش‌گرا با تصاویر مستقل موبایل و دسکتاپ و جای‌گذاری محتوا در فضای خالی تصویر
- نمایش چرخشی لوگوهای ترب‌پی، دیجی‌پی و اسنپ‌پی
- جستجوی مستقیم محصولات، دسته‌بندی‌های انتخابی و اسلایدر جدیدترین محصولات
- برگه فروشگاه (`/shop`) با آرشیو کامل محصولات به‌ترتیب تاریخ (جدید به قدیم)
- اسلایدر محصولات تخفیف‌دار بعد از جدیدترین‌ها با تنظیم روشن/خاموش و سرعت
- علاقه‌مندی‌ها با شورت‌کد `[rezajordaan_wishlist]` برای برگه `/wishlist/`
- بخش درباره ما و اطلاعات خرید حضوری
- کارت‌های «چرا ما؟» و فوتر کامل شامل لینک‌ها، تماس، روبیکا و اینماد
- پنل «نمایش ← تنظیمات رضا جردن» برای مدیریت محتوای لندینگ، راه‌های ارتباطی، پیوندها و کارت محصولات
- انتخاب مستقیم دسته‌بندی‌های لندینگ، چیدمان مستقل موبایل/دسکتاپ و شخصی‌سازی نام و قاب دسته‌ها
- فیلتر جمع‌شونده و هوشمند سایزهای موجود هر دسته همراه ورودی و اسلایدر قیمت
- شخصی‌سازی قاب محصول و متن/رنگ برچسب تخفیف و کنترل نمایش زیردسته‌ها
- جستجوی جمع‌وجور محصولات در هدر صفحات داخلی و حذف سایدبارهای پیش‌فرض ووکامرس
- قالب برگه استاندارد، قالب HTML/CSS اختصاصی و فهرست مقالات

## نصب

### دانلود

**نسخه 1.5.9 (آخرین):**

https://github.com/esmaeelsh93-lab/Esee/releases/download/rezajordaan-1.5.9/rezajordaan-installable.zip

**نسخه 1.5.8:**

https://github.com/esmaeelsh93-lab/Esee/releases/download/rezajordaan-1.5.8/rezajordaan-installable.zip

اگر لینک Release کار نکرد، از این آدرس مستقیم branch استفاده کنید:

https://raw.githubusercontent.com/esmaeelsh93-lab/Esee/cursor/rezajordaan-theme-8310/dist/rezajordaan-installable.zip

1. فایل zip را دانلود کنید.
2. در پیشخوان وردپرس بروید به `نمایش ← پوسته‌ها ← افزودن ← بارگذاری پوسته` و فایل را آپلود کنید.
3. ووکامرس را فعال و برگه فروشگاه را با نشانی `/shop` تنظیم کنید.
4. محتوای برگه فروشگاه را خالی کنید (شورت‌کدهایی مثل `[PRODUCTS]` لازم نیست؛ آرشیو توسط قالب رندر می‌شود).
5. در برگه `/wishlist/` فقط شورت‌کد `[rezajordaan_wishlist]` را بگذارید (شورت‌کد وودمارت کار نمی‌کند).
6. در `نمایش ← تنظیمات رضا جردن ← لندینگ و دسته‌بندی‌ها`، دسته‌های قابل نمایش را تیک بزنید.
7. اطلاعات تماس، پیوندهای هدر و فوتر و تنظیمات کارت‌ها را در همان پنل بررسی کنید.
