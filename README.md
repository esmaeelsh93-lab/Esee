# Parisa Crop

پوسته اختصاصی و راست‌چین فروشگاه اینترنتی [parisacrop.ir](https://parisacrop.ir) برای وردپرس و ووکامرس.

## امکانات

- هدر واکنش‌گرا با منوی همبرگری، دسته‌بندی‌های پویا و لینک مستقیم اینستاگرام/واتساپ
- هیروی تصویری واکنش‌گرا با تصاویر اختصاصی موبایل و دسکتاپ
- جستجوی مستقیم محصولات بلافاصله بعد از هیرو
- دسته‌بندی‌های انتخابی در سه ستون دسکتاپ و دو ستون موبایل
- اسلایدر پیوسته جدیدترین محصولات ووکامرس
- کارت‌های مربعی بخش «چرا ما؟» و فوتر کامل
- پنل سبک «نمایش ← تنظیمات پریسا کراپ» برای راه‌های ارتباطی، پیوندها و کارت محصولات
- قالب برگه استاندارد، قالب HTML/CSS اختصاصی و فهرست مقالات
- کنترل تعداد ستون، ابعاد تصویر و سرعت اسلایدر به‌تفکیک دسکتاپ و موبایل
- طراحی بر پایه پالت اختصاصی Parisa Crop

## نصب

1. پوشه پروژه را با نام `parisacrop` داخل `wp-content/themes` قرار دهید.
2. پوسته **Parisa Crop** را در وردپرس فعال کنید.
3. ووکامرس را نصب و برگه فروشگاه را با نشانی `/shop` تنظیم کنید.
4. در `محصولات ← دسته‌بندی‌ها`، گزینه «نمایش در صفحه اصلی» را برای دسته‌های موردنظر فعال کنید.
5. راه‌های ارتباطی، لینک‌های هدر/فوتر و ابعاد کارت‌ها را از `نمایش ← تنظیمات پریسا کراپ` وارد کنید.

## برگه‌ها و مقالات

- برگه‌های عادی به‌صورت خودکار با قالب خوانا و هماهنگ سایت نمایش داده می‌شوند.
- برای برگه‌های کدنویسی‌شده، قالب **HTML اختصاصی** را انتخاب و HTML را داخل بلوک HTML سفارشی وارد کنید. CSS همان برگه در کادر «تنظیمات نمایش پریسا کراپ» ثبت می‌شود.
- برای نمایش مقاله‌ها، یک برگه خالی مثل «مجله» بسازید و آن را در تب «پیوندها و برگه‌ها» به‌عنوان صفحه مقالات انتخاب کنید.
- هر برگه منتشرشده را می‌توان از همان پنل به هدر یا فوتر افزود.
