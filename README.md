# to3edev — Logo Concepts

دو کانسپت طراحی لوگو برای **to3edev**، استودیوی توسعه‌ی وب و افزونه.

## مشاهده

فایل `logo-concepts/index.html` را در مرورگر باز کنید تا هر دو کانسپت را همراه با
نسخه‌های رنگی/تک‌رنگ، پالت رنگی و تایپوگرافی ببینید.

## فایل‌های لوگو (SVG، وکتور و مقیاس‌پذیر)

مسیر: `logo-concepts/assets/`

### کانسپت ۰۱ — Pulse Bracket (فناورانه / گرادینت)
- `concept-1-icon-color.svg` — نسخه‌ی رنگی (برای زمینه‌ی روشن و تیره)
- `concept-1-icon-mono-black.svg` — تک‌رنگ سیاه (روی زمینه‌ی روشن)
- `concept-1-icon-mono-white.svg` — تک‌رنگ سفید (روی زمینه‌ی تیره)

### کانسپت ۰۲ — Studio Mark (مینیمال / ادیتوریال)
- `concept-2-icon-color.svg` — نسخه‌ی رنگی
- `concept-2-icon-mono-black.svg` — تک‌رنگ سیاه
- `concept-2-icon-mono-white.svg` — تک‌رنگ سفید

## تبدیل به PNG

چون فایل‌ها SVG هستند، در هر ابزاری (Figma، Illustrator، Inkscape یا حتی مرورگر)
می‌توانید آن‌ها را در هر اندازه‌ای به PNG خروجی بگیرید، بدون افت کیفیت.
