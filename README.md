## افزونه پیام‌رسان سفارش

پوشه `esee-order-messenger` یک افزونه ووکامرس است که بعد از ثبت و تکمیل سفارش، متن شخصی‌سازی‌شده را از طریق API رسمی واتساپ، بله و روبیکا می‌فرستد.

مشتری کانال را در تسویه‌حساب تیک می‌زند. تشخیص پنهان «آیا این شماره واتساپ/روبیکا/بله دارد» بدون سرور همیشه روشن و API غیررسمی ممکن نیست؛ جزئیات در `esee-order-messenger/README.md` است.
