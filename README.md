# Parisa Crop

پوسته اختصاصی و راست‌چین فروشگاه اینترنتی [parisacrop.ir](https://parisacrop.ir) برای وردپرس و ووکامرس.

## امکانات

- هدر واکنش‌گرا با منوی همبرگری، دسته‌بندی‌های پویا و لینک مستقیم اینستاگرام/واتساپ
- هیروی اختصاصی با انیمیشن‌های GSAP و المان چوب‌لباسی
- دسته‌بندی‌های انتخابی در سه ستون دسکتاپ و دو ستون موبایل
- اسلایدر پیوسته جدیدترین محصولات ووکامرس
- بخش «چرا ما؟» و فوتر کامل
- طراحی بر پایه پالت اختصاصی Parisa Crop

## نصب

1. پوشه پروژه را با نام `parisacrop` داخل `wp-content/themes` قرار دهید.
2. پوسته **Parisa Crop** را در وردپرس فعال کنید.
3. ووکامرس را نصب و برگه فروشگاه را با نشانی `/shop` تنظیم کنید.
4. در `محصولات ← دسته‌بندی‌ها`، گزینه «نمایش در صفحه اصلی» را برای دسته‌های موردنظر فعال کنید.
