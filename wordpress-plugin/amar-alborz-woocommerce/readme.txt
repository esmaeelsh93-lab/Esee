تحلیل هوشمند فروشگاه ووکامرسی: داشبورد آماری کامل، قیف فروش، منابع ورودی، گزارش شهر/دستگاه/مرورگر، تحلیل محصولات و دسته‌ها، درآمد و نرخ تبدیل و سبدهای رها شده؛ کاملاً فارسی، راست‌چین و واکنش‌گرا.

== توضیحات ==

آمار البرز یک افزونه‌ی اختصاصی تحلیل فروشگاه ووکامرسی است که تمام گزارش‌های خود را مستقیماً از رویدادهای واقعی ووکامرس و ردیابی سمت سرور می‌سازد؛ بدون هیچ تخمین یا حدس.

**ویژگی‌های اصلی**

* داشبورد آماری کامل با هدر برند و کارت‌های شاخص کلیدی (KPI)
* قیف فروش واقعی: بازدیدکننده ← مشاهده محصول ← افزودن به سبد ← تسویه‌حساب ← خرید نهایی
* منابع ورودی (گوگل، اینستاگرام، تلگرام، مستقیم، UTM و ...)
* گزارش شهرهای خریداران (بر اساس شهر واقعی فاکتور)، نوع دستگاه و مرورگر
* تحلیل محصولات و دسته‌بندی‌های پرفروش
* گزارش درآمد ناخالص/خالص، نرخ تبدیل و مرجوعی جداگانه
* تحلیل سبدهای رها شده به همراه محصولات واقعی داخل هر سبد
* منوی مستقل «آموزش» با راهنمای کامل فارسی

**منطق صحیح سفارش**

* هر سفارش فقط یک‌بار در آمار ثبت می‌شود، حتی اگر چند بار وضعیت آن تغییر کند.
* مبنای آمار فروش فقط وضعیت‌های «در حال انجام»، «تکمیل‌شده» و «در انتظار پرداخت» است.
* سفارش‌های «ناموفق» و «لغوشده» هرگز در فروش محاسبه نمی‌شوند.
* مرجوعی (Refund) همیشه به‌صورت جداگانه نمایش داده می‌شود، نه به‌صورت کسر پنهان از فروش.

**قابلیت‌های حرفه‌ای (نسخه تجاری)**

* Heatmap: نقشه‌ی حرارتی کلیک و اسکرول واقعی کاربران
* Session Replay: پخش مجدد مسیر حرکت/کلیک/اسکرول، بدون ذخیره‌ی اطلاعات حساس فرم‌ها
* هشدار هوشمند: تشخیص خودکار افت نرخ تبدیل، افزایش Bounce Rate، کاهش فروش و افزایش سبد رها شده
* گزارش UTM: تحلیل Campaign، Source، Medium و نرخ تبدیل هر کمپین
* A/B Testing (در نقشه توسعه)

**رابط کاربری**

* کاملاً فارسی و راست‌چین
* Mobile First و کاملاً واکنش‌گرا
* حالت روشن/تاریک (Dark / Light Mode)
* بدون Bootstrap؛ صرفاً CSS Grid و Flexbox
* راهنمای Tooltip فارسی کنار گزینه‌های پیچیده

== نصب ==

1. پوشه‌ی `amar-alborz-woocommerce` را در مسیر `wp-content/plugins/` سایت خود قرار دهید.
2. اطمینان حاصل کنید افزونه‌ی ووکامرس نصب و فعال است.
3. از بخش «افزونه‌ها» در پیشخوان وردپرس، افزونه «آمار البرز» را فعال کنید.
4. از منوی جدید «آمار البرز» در پیشخوان، داشبورد و گزارش‌ها را مشاهده کنید.
5. برای آموزش کامل، به منوی مستقل «آموزش» مراجعه کنید.

== سوالات متداول ==

= آیا داده‌ها به سرور خارجی ارسال می‌شوند؟ =
خیر. تمام داده‌ها فقط در دیتابیس همان سایت شما ذخیره می‌شوند.

= آیا Session Replay اطلاعات فرم‌ها را ذخیره می‌کند؟ =
خیر، هرگز. فقط مسیر حرکت، کلیک و اسکرول ذخیره می‌شود.

برای فهرست کامل سوالات متداول، به منوی «آموزش ← سوالات متداول» داخل افزونه مراجعه کنید.
